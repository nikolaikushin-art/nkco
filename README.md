# NK&CO — Management Consultancy & Business Brokerage

Website for NK&CO (React + CRACO + Tailwind).

## Layout
- `src/components/` UI, `brand/`, `mega/` (mega-menu), `ui/` (shadcn)
- `src/pages/` route-level pages
- `src/data/` content and menu data (`copy/` generated page copy)
- `src/lib/` helpers
- `src/styles/` all CSS (import order set in `src/index.js`)
- `scripts/` photo/copy tooling · `scripts/re/` Real Estate build scripts
- `docs/changelog/` CHANGES-vNNN.md history · `docs/README-original.md` earlier readme
- `.env.example` copy to `.env.local` and add keys

## Run
    npm install && npm start
    npm run build
